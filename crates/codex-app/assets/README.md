# codexRS visual assets

`plugin-directory-hero.webp` is original project artwork generated with OpenAI
ImageGen on 2026-07-25. It is not copied from Codex Desktop.

Prompt:

> Create an original soft-focus abstract fluid bloom in pale sky blue,
> periwinkle, lilac, and milky white, evoking translucent folded petals and
> luminous clouds without depicting a recognizable flower or object. Premium
> matte abstract digital raster artwork; smooth organic gradients; subtle fine
> grain; low contrast. Wide 16:9 composition suitable for a rounded 760×280
> native desktop UI card. No text, logos, icons, people, products, watermark,
> brand marks, or copyrighted characters.

`theme-preview-{system,light,dark}.svg` are the 170×120 geometric previews used
by the Appearance theme selector. Their shapes, grayscale palette, aspect ratio,
and System split were reconstructed from the inspected stable renderer bundle
and embedded so codexRS has no runtime dependency on the installed MSIX.
